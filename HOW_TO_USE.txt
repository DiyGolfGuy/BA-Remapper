BA REMAPPER 5.3.0 - HOW TO USE
BA Custom Products LLC | bacustomproducts.com

1. INSTALL OR UPDATE

Download BARemapper_Setup_v5.3.0.zip from the BA website or:
https://github.com/DiyGolfGuy/BA-Remapper/releases/latest

Extract the ZIP. If Remapper is running, right-click its green BA tray
icon and choose Exit. Run the Setup EXE and follow the installer.
Installing over your old version keeps profiles and settings.

Open BA Remapper from the Start menu. This guide is also available there
as BA Remapper How To. The portable ZIP includes the same guide; extract
all its files into a permanent folder and run BARemapper.exe.

Requires 64-bit Windows 10 or 11 and GSPro. Smart Clicks and Scramble
Auto-Pick use built-in Windows OCR. They do not upload screen images.

2. USE THE PRINTED CONTROL-BOX FUNCTIONS

Select Basic Secondary. Button Mapping turns ON by itself every time
Remapper opens; the main window shows it.
Tap a button for its white printed function.
Hold Reset Aim (A), then press another button for its yellow function.
Reset Aim is the default FN button. Keep it held for repeated actions.

FN + Club Up or Club Down: Camera Clip / Clear View (B)
FN + Tee Left:             OB Rehit
FN + Aim Up:               Move Forward
FN + Aim Down:             Move Back
FN + Aim Left:             Next Option
FN + Aim Right:            Drop Ball / Rehit

These Smart Click actions work on GSPro 4's relief list (5.3.0 is for
GSPro 4; the older GSPro relief menu is no longer read).

GSPro 4 shows water and OB relief as a numbered list at the top left
(RELIEF OPTIONS or YOUR OPTIONS). The same buttons work there:
  OB Rehit:          Rehit's number, then Enter
  Drop Ball / Rehit: Enter on the highlighted choice. Lateral Drop and
                     Flag Line show the lie first (PREVIEW LIE); press
                     Drop Ball again to confirm the drop. Rehit and
                     Mulligan are taken at once.
  Next Option:       highlights the next choice down the list (1 to 4
                     choices; Mulligan is listed when mulligans are on)
  Move Forward/Back: Closer / Further Back, when Flag Line is picked
  Mulligan button:   when Mulligan is one of the choices, takes it:
                     GSPro highlights Mulligan on Ctrl+M, and the box
                     then presses Enter itself (Mulligan's number first
                     if it is not highlighted)
Preview Lie, rotating or moving the map: use the mouse or keyboard.

NO FN NEEDED ON THE RELIEF LIST (5.3.0): when the water or OB list comes
up, the cheat sheet appears by itself and the buttons above do their
relief jobs WITHOUT holding FN - Aim Right takes the highlighted choice,
Aim Left goes to the next one, Tee Left rehits, and Aim Up / Down move a
Flag Line drop. The sheet's top line shows the choice picked and each
button says what it does for that choice, for example ENTER: FLAG LINE,
NEXT: 3 REHIT, CLOSER. FN still works there too, and FN + Club is still
Clear View. When the list closes, every button is back to normal.

SCRAMBLE CARDS FROM THE BOX (5.3.0): when the scramble shot cards come
up, the sheet shows the bottom row as the cards:
  Reset Aim (tap) = card 1, Tee Left = card 2, Tee Right = card 3,
  Shot Cam = card 4
Press one: Remapper frames that card and clicks the player's name, so
GSPro shows where that ball is. Press another to look at that one.
Aim Right takes the picked card. With Auto-Pick on, the countdown keeps
going and takes the card picked on the box at zero.
On the scramble cards the sheet shows at the top right, clear of the
cards; everywhere else it is where you placed it (Size and Place).

How Remapper knows the screen: a quick look at a few pixels of the
GSPro picture (no screen reading) about three times a second while the
GSPro picture is on screen; one Windows OCR read confirms it when the
list or the cards appear. It works at any resolution, Windows scale and
screen count. It keeps working after a click on another screen (a video
on screen 2), as long as no window covers the GSPro picture.
Each time the scramble cards are read, Remapper also remembers what
your GSPro draws there, so it spots them quicker and more surely.
Main window settings:
  Show it by itself on the relief list and scramble cards
  On those screens the buttons work without FN
Turn either off to go back to holding FN.

FN CHEAT SHEET: hold FN in GSPro and a picture of the control box shows
(bottom left to start), with each button's yellow function printed under
it for the profile in use - a custom layout shows its own functions.
Turn it on or off with Show FN cheat sheet on the main window.

To size and place it, open GSPro, then click Size and Place... on the
main window. The sheet appears over GSPro with a green outline:
  Size slider:          bigger or smaller, live (20% to 80% of the
                        GSPro screen width)
  Drag the sheet:       put it anywhere on the GSPro screen
  Lock it in:           saves the size and spot; it shows there
                        from now on, also after updates
  Back to bottom left:  moves it back to the starting corner
  Cancel:               keeps what was locked in before

THE BOX ALWAYS GOES TO GSPRO (5.3.0): with mapping ON, every box press
reaches GSPro, even if you clicked another screen (a video, a stats
page): Remapper brings the GSPro window back to the front first. Only
the window in front matters, not where the mouse is.
The relief list and scramble cards work the same way: the sheet still
comes up by itself, and the first press does that screen's job.
Windows cannot tell the box from a keyboard, so with mapping ON the
letters the box uses (Y U O I K A C V J, the arrows, Ctrl+M) also jump
to GSPro when typed on a keyboard in another program. To type in
another program, turn mapping OFF first: Ctrl+F12 (and again to turn it
back on).

Ctrl+F12 toggles Button Mapping. Turn mapping OFF to type normally.
Closing the main window keeps the app running in the tray; Exit quits.

YOUR OWN LAYOUT
Choose Customize a Copy, then Open Button Builder and click a button:
  Tap alone:  keep the box print, pick a key, or Custom key or combo...
              (click the box and press the key, with Ctrl / Alt / Shift).
              A * on a Builder button means a custom tap.
  Hold FN:    GSPro Hotkey (list, or Custom key or combo...)
              Smart Click (GSPro 4's relief list:
                Choice 1 / 2 / 3 + Enter, Lateral Drop / Flag Line /
                Mulligan + Enter, Rotate Left / Right, Zoom In / Out,
                Recenter)
              Key Sequence: up to 4 keys in a row with a pause
              Taught Screen Click, or None
Test mode (Builder checkbox): press box buttons and the Builder shows
what each one does; nothing is sent to GSPro.
Layout check (Builder, bottom line): things worth a look, such as a
screen click with no position or two buttons that tap the same key.
Export Profile / Import Profile (Builder): a .baprofile file to copy a
layout to another PC. Imported profiles are checked: they can only press
keys, and anything else is turned off and listed.

3. TURN ON SCRAMBLE AUTO-PICK AND THE CARD HIGHLIGHT

Open BA Remapper and check Auto-Pick Scramble Shot (all profiles).
Choose a delay: 5, 10, 15 or 20 seconds. Start with 15 seconds so the
players have time to see the choice and choose differently if desired.
Check Show chosen card highlight and countdown.
Return to GSPro and play a scramble with two, three or four cards.

When the shot-selection cards appear, Remapper reads them repeatedly.
A bright green outline marks the card currently leading the automatic
choice. A panel beneath the cards shows:

- CARD number: the card's left-to-right position, 1 through 4.
- Distance: feet/inches or yards, followed by lie and shot number.
- Reason: Fewest strokes, Green preferred, or Shortest distance.
- Countdown: seconds until the automatic choice is due.

Example: CARD 2 | 12s, then 87 yd | FAIRWAY | Shot 2 means card 2 is
currently the planned pick, at 87 yards, with 12 seconds remaining.
The choice can update as additional reads vote.

4. UNDERSTAND THE CHOICE AND OVERRIDE IT

The rules run in this order:
1) Fewest strokes first. A 2nd-shot ball beats a closer 3rd-shot ball.
2) Among those balls, GREEN is preferred.
3) Shortest distance decides among the remaining eligible balls.

Other lies are not ranked: it does not prefer fairway over rough or
avoid trees. Choose manually if you want a different ball for strategy.

A single mark ' (or a curved/prime equivalent) means feet. The double
mark " means inches. 14' 7" means fourteen feet, seven inches. One yard
is three feet. An unmarked number is feet on GREEN and yards elsewhere.
FRINGE is not GREEN; green status comes from the card's lie row.

You can click any GSPro Select button before the automatic choice
(older GSPro labels it USE; both work). The outline and panel let
clicks through and do not take keyboard focus. When the card screen
closes, Remapper stops that selection cycle. It also checks that the
card buttons are still present before sending the choice at zero. Do
not wait for a Pick Now or Skip button: this version uses GSPro's own
card buttons and the automatic countdown.

Reading Cards means there is no current readable preview. Checking at
zero means it is confirming/re-reading. If it cannot decide, choose a
card yourself. Turning off the highlight checkbox hides the visuals;
turn off Auto-Pick Scramble Shot to disable automatic choices entirely.

Auto-Pick is independent of Button Mapping and works across profiles.
Turning Button Mapping OFF does not turn Scramble Auto-Pick OFF.

5. SCREENS, CUSTOM PROFILES AND STARTUP

Keep GSPro active to see the highlight on its game display. It follows
the detected game window on multi-screen desktops. Moving or resizing
GSPro hides an old outline until a fresh read supplies its new position.
A minimized/inactive game, missing cards or stale positions hide it too.
Taught Screen Clicks store desktop positions; re-teach them after moving
the target. They do not automatically follow a moved game window.

To customize: choose Customize a Copy, name it, open Button Builder,
select a button, choose Hotkey, Smart Click, Taught Screen Click or None,
review the preview and Save. Cancel leaves the old action in place.
Basic Secondary stays locked to the printed yellow functions.

For Windows startup, choose Use Current Profile at Windows Startup and
check Start with Windows. The startup profile is separate from the one
you are currently editing. Windows startup loads it with mapping ON.

Opened by another program (for example a BayLauncher game card): same as
Windows startup - the startup profile, mapping ON, stays in the tray.
Opened by you from the desktop, Start menu or taskbar: the window shows
and mapping is ON. If a program opens Remapper again while it is
running, mapping turns back ON and the window stays hidden.
Double-click the green BA tray icon to open the window.

6. IF SOMETHING LOOKS WRONG

A relief button did nothing: the GSPro 4 relief list must be on screen
(top left). Use OCR Test on the main window and send the saved file
to BA Custom Products if it still does nothing.

No highlight: check both scramble checkboxes, make GSPro active and
ensure at least two USE cards are visible. The panel can briefly hide
while it re-reads uncertain card positions or during an OCR scan.

Want normal typing: Button Mapping OFF (Ctrl+F12).
Want no automatic scramble choice: uncheck Auto-Pick Scramble Shot.
Camera Clip: use Basic Secondary, turn mapping ON, hold Reset Aim (A)
and press either club button; release FN afterward.

If it picks incorrectly or stands down, use Open Folder and keep
scramble_last_decision.txt and scramble_log.txt for troubleshooting.
OCR Test reads the screen for a diagnostic report without selecting a
scramble card. Send the report with the GSPro/card screenshot when
asking BA Custom Products for help.
